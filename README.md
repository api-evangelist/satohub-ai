Sato Hub is a daily-rebuilt, evidence-scored index of on‑chain AI agents, listing frameworks, MCP servers, wallets, payment rails and data tools. It provides install checks, agent‑economy metrics, and a searchable directory of 488 scored listings across 28 chains. The platform has no token and is dedicated to transparent AI agent tooling.

**Areas:** Company · AI · Blockchain · Crypto · Agent
